# Tech Stack — Parling-Academy

## Core
- **Type**: Static landing page
- **Language**: Vanilla HTML5 + CSS3 (single `index.html` file)
- **No build step** — open directly in browser or serve with any static server

## Serving locally
```bash
npx serve . -l 3000
# or
python3 -m http.server 3000
```
Public URL: `https://code.kenitech.io/preview/3000/`
