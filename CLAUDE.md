# Parling-Academy

Landing page for the Parling language-learning platform. Single `index.html` — vanilla HTML/CSS, no build step.

## Rules
- Tech stack → `.claude/rules/tech_stack.md`
- Coding style → `.claude/rules/coding_style.md`
- UI / design tokens → `.claude/rules/ui_guidelines.md`

## Serve locally
```bash
npx serve . -l 3000
```
Public URL: `https://code.kenitech.io/preview/3000/`

## Environment note
Runs behind `https://code.kenitech.io`. Use relative paths for assets (no leading `/`).
Reserved ports to avoid: 2019, 8080, 9001.
